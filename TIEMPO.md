# Registro de Tiempos de Desarrollo — TIEMPOS.md

Este documento recoge el tiempo dedicado a la realización de las tareas iniciales del proyecto para el microfrontend **Descubrimiento** (`tienda-ucjc-descubrimiento`).

---

## 📊 Resumen por Tareas

| Punto | Tarea / Entregable | Tiempo Invertido |
| :-: | :--- | :-: |
| **1** | Formación de equipo, asignación de responsable y envío de correo a la coordinación | 1 min |
| **2** | Creación del repositorio en GitHub e invitación enviada al profesor César | 5 min |
| **3** | Redacción del `README.md` (pieza, integrantes, responsable y Custom Element) | 5 min |
| **4** | Inicialización del proyecto Vite (`npm run dev`) y renderizado básico del Custom Element | 15 min |
| **5** | Redacción del borrador de eventos a emitir/consumir y definición de payloads | 30 min |
| **6** | Creación y formateo del archivo `TIEMPOS.md` | 5 min |
| **Total** | **Tiempo Total para completar los Puntos 1 a 5** | **1h 02min** |

---

## ⏱️ Desglose Detallado

1. **Punto 1 (1 min):** Organización del equipo, designación del responsable y envío del correo informativo con el nombre del equipo, integrantes, responsable y URL del repositorio.
2. **Punto 2 (5 min):** Creación y configuración del repositorio remoto en GitHub (`tienda-ucjc-descubrimiento`) y envío de invitación de colaboración a `cesar.andress@ucjc.edu`.
3. **Punto 3 (5 min):** Creación del `README.md` con los datos identificativos: pieza asignada (*Descubrimiento*), miembros del equipo, responsable y nombre del Custom Element (`<ucjc-descubrimiento>`).
4. **Punto 4 (15 min):** Configuración del entorno base con Vite, arranque del servidor de desarrollo (`npm run dev`) y comprobación de la renderización básica «Soy Descubrimiento».
5. **Punto 5 (30 min):** Elaboración del borrador de eventos DOM (`ucjc:cart:add-item`, `ucjc:session:changed`, `ucjc:cart:updated`), definiendo emisores, receptores y los esquemas JSON de cada *payload*.
6. **Punto 6 (5 min):** Creación del archivo `TIEMPOS.md` registrando la suma total de dedicación a los puntos anteriores.
